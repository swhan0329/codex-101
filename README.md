# Codex 101

A Korean and English guide for people getting started with Codex.
Practical examples and links to official documentation help you start small and review the results.

- [Read the guide](https://swhan0329.github.io/codex-101/)
- [Explore use cases](https://swhan0329.github.io/codex-101/use-cases.html)
- [Daily checks and source history](DAILY_CHECKS.md)
- [Official documentation](https://learn.chatgpt.com/docs)
- [한국어 소개](README_KO.md)

## What you’ll find

- Getting started, projects, permissions, and reviewing results.
- Practical tasks with Korean and English prompts.
- Source-linked tips and guidance.

## Site files

- `index.html` contains the main guide.
- `use-cases.html` and `use-cases-data.js` contain the catalog and its data.
- `i18n.js` contains Korean and English interface and guide text.
